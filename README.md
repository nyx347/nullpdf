An egui front end for pdfium.

Does what a PDF reader should do, but also, basic and intuitive annotations.

- freeform drawing and highlighting with easy to draw straight lines (hold shift)
- add text anywhere
- rotate the whole document to any angle by right-click draging
- one touch keyboard shortcuts for quick navigation and editing
- minimal UI, tab to hide entirely
- single binary for portability and use on locked down systems
- annotations saved in sidecar file allowing for changing to underlying pdf while keeping annotations

Built primarily to make marking up plans exported from CAD programs quick and easy while allowing for re-exporting new versions while keeping annotations.
